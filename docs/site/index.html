Frequently Asked Questions

Is Zoffice affiliated with Microsoft?

No. Zoffice is an independent open-source project and is NOT affiliated with, sponsored by, or endorsed by Microsoft Corporation or any of its subsidiaries in any way. Zoffice is an original software suite developed under the MIT License by independent contributors.

Is Zoffice really 100% offline-first?

Yes. Zoffice makes zero outbound network connections during everyday use. Fonts and icons are bundled locally into the installer, and databases run in-process using local SQLite.

Can I open files created in Microsoft Office?

Yes. Zoffice includes native readers and writers for Open XML formats (.docx, .xlsx, .pptx) alongside standard open formats (.odt, .ods, .csv, .md, .svg).
